# 景园第一阶段目录
## 学习中遇到的问题及解决办法
#### 目前我遇到的问题
1. VScode的上手不是很熟练，配置环境和软件的插件不是很了解，一开始终端里全是乱码，根本不能跑代码
2. 没有使用机场的经验，不会挂梯子，造成edX网站访问学习变得极为困难
3. 有很多软件不认识，对后面的学习造成了很大障碍，导致有很多时间并不是在学习python而是在“补课”
4. 自身英语水平不过关，第一次接触这种学习方式有些不太适应

#### 目前我对以上问题的解决办法
1. 对于VScode来说没有捷径，只有多练习，终端乱码问题是因为环境变量添加的不对已经咨询学长解决
2. 在仔细阅读群内链接内容后已经学会相关知识，edx网站访问流畅并且开始浏览课程笔记内容学习
（一开始因为没梯子登不上edX网站都是在B站上学习的，笔记都是自己记的，一边上课一边记笔记速度挺慢的，现在一边上课一边实操加深印象）
3. 为了减少障碍，先去学习其他软件的用法巩搭建基础，后续会在学习python的过程中查漏补缺
4. 英语是我的一大硬伤所以我也很重视后续会去补课，这种学习方式渐渐适应了只要一直坚持就没问题
